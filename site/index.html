apfelkäfig

Disposable dev sandboxes on Apple Silicon, safe to point coding agents at.

akf up boots your project inside an Apple container micro-VM with Claude Code (or any CLI agent) running with --dangerously-skip-permissions. The VM is the sandbox, so the permission prompts are redundant, not risky.

Try it

# drive-by from any directory — no setup
akf up                         # interactive Claude in the built-in image
akf up bash                    # drop into a shell
akf clean                      # leave no trace

macOS on Apple Silicon · requires Apple container 1.0+ · pre-release (v0.2)

Install from source

git clone https://github.com/schmidsi/apfelkaefig
cd apfelkaefig
deno task compile
cp dist/akf /usr/local/bin/akf

Homebrew and npm (npx apfelkaefig init) are on the way.
